# kihonQuest — 2級建築士4科目ゲーム設計書

## 0. 前提

- 対象：短大生レベルの建築知識ゼロから受験できる学習者
- プラットフォーム：ブラウザ（GitHub Pages）+ スマホ対応
- 1科 = 1ワールド。4ワールドをクリアして建築士合格

---

## 1. 構造（STRUCTURE）— 物理シミュレーション型

### 1.1 科目特性
- 図形 + 数式 + 直感
- S図・M図・応力度・たわみ
- 橋の種類と力の使い分け

### 1.2 最適ゲーム要素
| 要素 | 実装 | 学習内容 |
|------|------|---------|
| ドラッグ物理 | Canvas マウス/タッチ操作 | 曲げ・たわみ・破断を体感 |
| ストレスカラー | 赤→青緑のグラデーション | σ/fb の比率を直感化 |
| ヒットポイント（HP） | 梁の"耐久値" | 許容応力度を超えると減少→0で破断 |
| スコア | σ/fb を最小化した設計点数 | 断面係数Zの最適化トレーニング |
| ボス戦 | 過去問の図を読んで3秒で判断 | S図・M図の即答力 |
| アイテム | 材料変更（木→鋼→RC） | E・fb の値の違いを暗記 |

### 1.3 ワールド構成
```
 Stage 1-1: はりの基本        ← 片持ちドラッグ（現已完成）
 Stage 1-2: S図M図           ← forces.html（現已完成）
 Stage 1-3: 桁橋の力         ← beam.html（現已完成）
 Stage 1-4: アーチ vs 吊り    ← arch.html + suspension.html（現已完成）
 Stage 1-5: トラス           ← truss.html（現已完成）
 Stage 1-6: 応力の4種類       ← stress.html（現已完成）
 Stage 1-7: ボス「過去問10連」
```

### 1.4 UIパターン
- **画面3分割**: Canvas上部（図）| 数値中部（σ・Z・δ）| コントロール下部
- **色分け**: 安全(緑)→注意(黄)→危険(赤)→破断(黒)
- **リアルタイム**: スライダー/ドラッグで即反映

## 2. 環境（ENVIRONMENT）— パラメータ調整・フロー可視化型

### 2.1 科目特性
- 比例・計算式中心（Q=CA√(2gh) など）
- 室内温熱環境・換気・採光・音
- 数値が変わると気持ち良いフィードバック

### 2.2 最適ゲーム要素
| 要素 | 実装 | 学習内容 |
|------|------|---------|
| スライダー調整ゲー | 温度・風量・日射量スライダー | PID的なバランス感覚 |
| ヒートマップ | Canvas平米グリッドが色変化 | 温度分布・冷橋の理解 |
| 能源フロー図 | サンキー風アニメーション | 熱損失・日射取得・機械暖房の流れ |
| アバター体感 | 室内に人アイコンを配置 | PMV・快適度の数値化 |
| 天気連動 | 地域×季節の気象データ | 夏冷房/冬暖房の負荷差 |
| コスト連動 | 断熱性能↑ = 初期費↑/運用費↓ | LCC（ライフサイクルコスト）のトレードオフ |

### 2.3 ワールド構成
```
 Stage 2-1: 熱の流れ          ← 断熱材スライダー→熱貫流係数U値
 Stage 2-2: 採光計算          ← 窓位置/大きさスライダー→採光係数
 Stage 2-3: 換気シミュ        ← 換気回数スライダー→CO2濃度
 Stage 2-4: 音環境            ← 壁の厚さ/比重スライダー→遮声音
 Stage 2-5: 給排水            ← 水量/圧力スライダー→配管径
 Stage 2-6: 全面最適化         ← 熱+光+音+換気のバランス調整
 Stage 2-7: ボス「環境計画」
```

### 2.4 UIパターン
- **部屋断面図**: 壁/窓/屋根をSVGで表示、スライダーで厚み変更
- **数値ガイジ**: 温度/快適度/CO2/音圧レベルをゲージ表示
- **比較モード**: A棟（良い設計）vs B棟（悪い設計）の並列表示
- **年間アニメーション**: 再生ボタンで1年の室温変化を高速再生

## 3. 施工（CONSTRUCTION）— 工程管理・リスクシミュレーション型

### 3.1 科目特性
- 工程順序・資材・安全管理
- 実務的発想（「こっち先やったら危ない」）
- 建築基準法の施工関連条文

### 3.2 最適ゲーム要素
| 要素 | 実装 | 学習内容 |
|------|------|---------|
| デッキ構築（工程順序） | ドラッグで作業カードを並べる | 先順約束・近接作業の制約 |
| ガントチャート | Canvas or SVG横棒グラフ | 工期・フロート・クリティカルパス |
| リスクカード | 毎ターン山札から引く | 雨天・事故・資材遅延の対応 |
| 資源管理 | 予算/人員/資材の3リソース | 原価管理・資材納期 |
| 安全マトリクス | 3×3グリッドで対策配置 | 墜落・落下物・近接の予防 |
| 品質判定 | コンクリート強度ヒストグラム | 管理限界・規格値 |

### 3.3 ワールド構成
```
 Stage 3-1: 基礎工           ← 土留め→掘削→布石→配筋→打設の順序
 Stage 3-2: 躯体工           ← 型枠→配筋→打設→養生のチェックリスト
 Stage 3-3: 鉄骨建方          ← クレーン選定→高力ボルト→溶接管理
 Stage 3-4: 仕上・防水        ← 防錆→防水→外装の順序（下塗り→中塗り→上塗り）
 Stage 3-5: 安全管理          ← リスクカードに対して対策カードを配置
 Stage 3-6: 全面施工計画       ← 90日ガント全体を組む
 Stage 3-7: ボス「実地試験」   ← 過去問+施工順序穴埋め
```

### 3.4 UIパターン
- **カードベース**: 作業カード（工期/コスト/要件）を手札から配置
- **ターン制**: 1day = 1ターン。天候イベント→作業実行→リスク判定
- **ミニマップ**: 建物断面が左上、工程進捗が色で上書きされていく
- **アラートポップアップ**: 「コンクリート打設開始から1.5h経過！次の打設まで急げ」

## 4. 法規（REGULATION）— ケース判定型クイズRPG

### 4.1 科目特性
- 条文・数値・敷地/建築/設備の3分野
- 「ここは通路なので幅を」などの即座判定
- 間違い探し・数値暗記が主体

### 4.2 最適ゲーム要素
| 要素 | 実装 | 学習内容 |
|------|------|---------|
| 敷地マップ編集 | 敷地内に建物を配置、境界/道路/隣地チェック | 建蔽率・容積率・斜線制限 |
| 間違い探し | 建物断面図に法規違反をN個埋め込む | 階段数・避難経路・天井高 |
| 数値クイズ | 3秒バトル（素早く数値を答える） | 居室床面積下限・廊下幅・階段幅 |
| 条文マッチング | 条文＋ケースの組み合わせ | 用途地域・防火・避難 |
| 建築確認検査 | 書類にチェックを入れて提出 | 確認申請の手続き・図書 |

### 4.3 ワールド構成
```
 Stage 4-1: 敷地法規         ← 建蔽率/容積率パズル
 Stage 4-2: 建築構造法規      ← 耐火/防火/避難経路チェック
 Stage 4-3: 設備法規          ← 換気/採光/給排水の設備基準
 Stage 4-4: 道路斜線          ← 道路・隣地斜線を3D表示で確認
 Stage 4-5: 用途地域          ← 12地域別に用途をマッチング
 Stage 4-6: 確認申請          ← 書類チェックミニゲーム
 Stage 4-7: ボス「法規総合」   ← 過去問ランダム20連
```

### 4.4 UIパターン
- **トップダウン敷地図**: 道路/隣地/建物をドラッグ配置、リアルタイムで率表示
- **断面スキャナ**: 断面図をスクロールしながら「違反部分をタップ」
- **3秒バトル**: 問題表示→3秒カウント→選択肢タップ。素早さでボーナス
- **条文カード**: 条文をカード化、デッキ構築して「適用条文を選択」

## 5. 4科目統合システム

### 5.1 共通ゲームシステム
| 要素 | 4科目での使い回し |
|------|----------------|
| HP（建築許可値） | 構造=梁耐久度、環境=快適度、施工=安全点数、法規=法令適合率 |
| MP（知力） | 過去問解答に消費、1日回復 |
| 経験値 | 各StageクリアでUP、レベルアップで新案件解放 |
| 称号 | 「はりの達人」「計画マスター」「法規のプロ」など |

### 5.2 オープニング → 科目選択
```
[タイトル] kihonQuest
    ↓
[プロフィール設定] 名前 + アバター
    ↓
[ワールドマップ]
  ├─ 🏗️ 構造の洞窟  (進捗: 6/7)
  ├─ 🌡️ 環境の温室  (進捗: 0/7)
  ├─ 🏗️ 施工の現場  (進捗: 0/7)
  └─ 📋 法規の図書館 (進捗: 0/7)
```

### 5.3 最終ボス「2級建築士試験」
4科目のStage 1-7〜4-7を全てクリアでアンロック
- ランダムで4科目×5問 = 20問
- 時間制限あり
- 合格ライン60%→仮合格、80%→本合格、100%→トップ合格
