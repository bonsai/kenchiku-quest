# kihonQuest — 統合開発ISSUES（1枚管理）

## プロジェクト概要

- **目標**: 2級建築士試験4科目（構造・環境・施工・法規）をブラウザゲーム化
- **対象**: 短大生レベルの建築知識ゼロからの学習者
- **URL（予定）**: https://bonsai.github.io/kihonQuest/
- **技術**: HTML5 + CSS3 + Vanilla JS + GitHub Pages
